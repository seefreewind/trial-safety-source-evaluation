# Revision annotation dictionary

A: equal counts and all critical context verified; no retained record qualifies.
B: matching counts with incompletely verified context.
C: unresolved numerical difference without an established explanation.
D: documented population or reporting-period difference, not proof that the difference causes the count discrepancy.
E: ineligible for aligned numerical comparison owing to an explicit out-of-window event.

VERIFIED is support for the documented interpretation, not full numerical alignment. PARTIALLY_VERIFIED retains checked numerical values with unresolved context. SOURCE_i_REPORTED_PERCENT preserves the source display, null for registry percentages. SOURCE_i_RECALCULATED_PERCENT is 100*n/N and never overwrites the display. CONTEXT_ALIGNMENT_CERTIFIED is false for every retained record. Historical and newly verified labels are separate. No independent duplicate adjudication is claimed.
